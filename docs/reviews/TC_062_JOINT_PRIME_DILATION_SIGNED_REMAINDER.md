### 2.2 Exact Complete Signed Kernel $\mathcal{H}_Y(m, n)$ (`CONCRETE_ANALYTIC_IN_LEAN`)

For $Y \ge 2$, $T = T(Y) = \lceil Y^{5/4}\rceil$, $D_0 = \lfloor\log Y\rfloor$, $N = 2T$, and positive integers $m, n \le N$, set [`cutoffIndicatorT`](file:///c:/Development/Projects/reimann_scope/formal/RiemannScope/JointPrimeDilationSignedRemainder.lean#L50-L54) $t_n := \mathbf{1}_{1 \le n \le T}$, [`signedAdjustedCoeffB`](file:///c:/Development/Projects/reimann_scope/formal/RiemannScope/JointPrimeDilationSignedRemainder.lean#L55-L61) $b_n := \lambda(n)\beta_Y(n)$ (using $\lambda(n)^2 = 1$ so $\beta_Y(n) = \lambda(n) b_n$), $c(m, n) := \sum_{p^k \mid \gcd(m,n),\, k \ge 1} (\log p)^2$, and $G_Y^{[r]}(m, n) := \int_Y^{\tau Y} \frac{\varphi_m(X)\varphi_n(X)}{(\log X)^r}\,\frac{dX}{X}$. Define the symmetric kernel [`completeSignedKernelHcal`](file:///c:/Development/Projects/reimann_scope/formal/RiemannScope/JointPrimeDilationSignedRemainder.lean#L62-L75) to vanish outside $[1, N]^2$, and on $1 \le m, n \le N$ by:
$$\mathcal{H}_Y(m, n) := t_m t_n G_Y^{[0]}(m, n) - \Bigl[t_m b_n + b_m t_n + 4 t_m t_n c(m, n) + 4\mathbf{1}_{m=n} t_m\bigl((\log m)^2 - c(m, m)\bigr)\Bigr] G_Y^{[2]}(m, n) + b_m b_n G_Y^{[4]}(m, n).$$

**Theorem 1 (`reassembly_known_part_and_complete_signed_kernel_tc062`)**: *For all $Y \ge 2$, $T \ge 1$, $D_0 \in \mathbb{N}$, and $(c_\lambda, c_{1/2})$ — and concretely on the canonical schedule at `(actualSelbergConstantCLam, actualSquarePoleConstantCHalf)` — $\mathcal{H}_Y(m, n) = \mathcal{H}_Y(n, m)$, $\mathcal{H}_Y(m, n) = 0$ outside $[1, 2T]^2$, and*
$$F(Y) = 4\widetilde{X}_{\mathrm{off}}(Y) + \|B_Y\|_Y^2 - 4\langle P_Y, B_Y\rangle_Y = \sum_{m=1}^{2T}\sum_{n=1}^{2T} \lambda(m)\lambda(n)\,\mathcal{H}_Y(m, n).$$
