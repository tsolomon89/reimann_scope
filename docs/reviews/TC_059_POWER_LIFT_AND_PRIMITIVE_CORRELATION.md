## 2. Exact Finite Dyadic Power-Lift, Meromorphic Separation, and Attempt A

### 2.1 Finite Dyadic Power-Lift Arithmetic (`UNCONDITIONAL_FINITE_ARITHMETIC` + Outside-Lean $O(\log\log T)$ Note)

Define $a_j(n) := \lambda(m)$ if $n = m^{2^j}$ ($j \ge 0$) and $0$ otherwise, and for $J \ge 1$ set $d_J := 2^J$ and $b_J := a_0 * a_1 * \dots * a_{J-1}$. In [`dyadic_power_lift_divisor_prime_power_and_stabilization_tc059`](../../formal/RiemannScope/DyadicPowerLiftPrimitiveCorrelation.lean#L659-L918), all nine finite arithmetic properties are proved unconditionally in Lean 4:

1. **Prime-Local Formal Power-Series & Polynomial Identity**: Over $\mathbb{Z}[t]$, $(1 - t)\prod_{0 \le j < J}(1 + t^{2^j}) = 1 - t^{d_J}$, matching $\prod_{0 \le j < J}(1 + t^{2^j})^{-1} = \frac{1 - t}{1 - t^{d_J}}$ in $\mathbb{Z}[[t]]$.
2. **Exact Power-Divisor Formula**: For every $J \ge 1$ and $n \ge 1$,
   $$b_J(n) = \sum_{r^{d_J} \mid n} \mu\!\left(\frac{n}{r^{d_J}}\right), \qquad b_1(n) = \lambda(n).$$
3. **Prime-Power Residue Formula**: For every prime $p$ and integer $e \ge 0$,
   $$b_J(p^e) = \begin{cases} 1 & \text{if } e \equiv 0 \pmod{d_J}, \\ -1 & \text{if } e \equiv 1 \pmod{d_J}, \\ 0 & \text{otherwise.} \end{cases}$$
4. **Exact Stabilization Threshold & First Discrepancy Boundary**: $b_J(n) = \mu(n)$ for all $1 \le n < 2^{d_J}$, while at the exact boundary $n = 2^{d_J}$ ($4, 16, 256, 65536$ for $J = 1, 2, 3, 4$), $b_J(2^{d_J}) = 1 \ne 0 = \mu(2^{d_J})$ and $\Delta_J(2^{d_J}) = -1$. On squarefree integers ($\mu(n)^2 = 1$), $b_J(n) = \mu(n)$ for **every** $J \ge 1$.
5. **Stabilization Depth $J_T$ (`UNCONDITIONAL_FINITE_ARITHMETIC` Exact Inequalities vs `ANALYTIC_PROVED_OUTSIDE_LEAN` Asymptotic)**: Lean formalizes the exact least-depth inequalities $T < 2^{2^{J_T}}$ and $(1 < J_T \implies 2^{2^{J_T - 1}} \le T)$ ($J_T = 1$ for $T \le 3$, $2$ for $4 \le T \le 15$, $3$ for $16 \le T \le 255$, $4$ for $256 \le T \le 65535$); taking iterated base-$2$ logarithms outside Lean yields the analytic asymptotic $J_T = \lfloor\log_2\log_2 T\rfloor + 1 = O(\log\log T)$ for $T \ge 4$ (distinct from an asymptotic Big-$O$ theorem inside Lean). Tower depth $J_T$ is strictly distinct from dyadic magnitude shells $\lfloor\log_2 T\rfloor$ and prime-power counts.
6. **Control Separation at $J = 2$**: For any completely multiplicative $a$, $(a_0 * a_1)(p^2) = a(p)(a(p) + 1)$, which vanishes at prime $p$ iff $a(p) \in \{0, -1\}$. Thus $b_{a,2}(p^2) = 0$ for all primes iff $a = \lambda$; for $\mathbf{1}$ it equals $2$ at every prime, for $a_2$ it equals $2$ at odd primes ($p = 3$), and for $a_{\{3,5,7\}}$ it equals $2$ at $p = 2, 11$.
