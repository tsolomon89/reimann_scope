### 2.1 Geometric Filter Definition and Uniform Bound (§2)

In [`LiouvilleSquareDilation.lean`](../../formal/RiemannScope/LiouvilleSquareDilation.lean#L7216-L7425) (`growingLogFilterPoly`, Theorem 30(4)) and [`tc/simultaneous_compatibility_combined_energy.py`](../../tc/simultaneous_compatibility_combined_energy.py), the finite growing-order filter for integer $M \ge 1$ and **real** $u \in \mathbb{R}$ is the geometric sum

$$P_M(u) = \sum_{m=0}^{M-1} (1 - u)^m, \qquad u\,P_M(u) = 1 - (1 - u)^M,$$

satisfying for all integers $M \ge 1$ and all **real** $u \in [1/4, 3/2]$:

$$0 < P_M(u) \le 4.$$

$$\bigl|\sqrt{J} - \sqrt{E}\bigr| \le \sqrt{\rho}, \qquad |J - E| \le 2\sqrt{E\rho} + \rho.$$

### 2.4 Selberg Second-Order Cancellation Provenance (§5)

Let $\Lambda$ be the von Mangoldt function, $B(r^2) := \Lambda(r)$ for $r \ge 1$ and $B(n) := 0$ when $n$ is not a square, and $*$ denote Dirichlet convolution, so $\Lambda_\lambda = -\Lambda + 2 B$. Expanding $w_{2,\lambda} = \Lambda_\lambda \log + \Lambda_\lambda * \Lambda_\lambda$ gives

$$w_{2,\lambda} = (-\Lambda + 2 B)\log + (-\Lambda + 2 B) * (-\Lambda + 2 B) = -\Lambda\log + \Lambda * \Lambda + 2 B\log - 4\Lambda * B + 4 B * B.$$

- **Corrected explanation**: The leading $d\log d$ cumulative terms cancel between $-\Lambda\log$ (cumulative $-d\log d + O(d)$) and $\Lambda * \Lambda$ (cumulative $+d\log d + O(d)$ by Dirichlet hyperbola + PNT). The $B$-dependent terms do **not** need to supply a $-2 d\log d$ cancellation, and $\Lambda * B$ is supported on prime-power-times-square integers $p^a r^2$ (for example $(\Lambda * B)(12) = \Lambda(3) B(4) = (\log 3)(\log 2) > 0$), **not** only on squares. Combined with PNT for $\lambda$ (`TC-057R` §4 Theorem 4.3(3)),
