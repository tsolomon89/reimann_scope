## 4. Controls, Exact Matched Drift Compensation, and Attribution to TC Arithmetic

### 4.1 Exact Second-Order $z = 1$ Laurent Compensation for Fixed Finite-Prime Parity Controls (`ANALYTIC_PROVED_OUTSIDE_LEAN`)

For any finite prime set $S$ ($S = \emptyset$ giving $a_\emptyset = \mathbf{1}$, $S = \{2\}$ giving $a_{\{2\}}$, and $S = \{3, 5, 7\}$ giving $a_{\{3,5,7\}}$), the completely multiplicative parity sequence $a_S(n) := (-1)^{\sum_{p \in S} v_p(n)}$ satisfies $D_{a_S}(z) = \zeta(z)\prod_{p \in S}\frac{1 - p^{-z}}{1 + p^{-z}}$, which retains a **simple pole** at $z = 1$ (unlike $D_\lambda(z) = \zeta(2z)/\zeta(z)$, which has a simple zero at $z = 1$). Consequently:
- Its convolution $(\mathbf{1} * a_S)(n) = \prod_{p \in S}\frac{1 + (-1)^{v_p(n)}}{2}$ vanishes iff some $p \in S$ divides $n$ to an odd power (`1` for all $n$ when $S = \emptyset$).
- Its logarithmic derivative satisfies $\frac{D_{a_S}'(1+u)}{D_{a_S}(1+u)} = -\frac{1}{u} + \gamma_E + \sum_{p \in S}\frac{2 p\log p}{p^2 - 1} + O(u)$ as $u \to 0$ (since $\frac{d}{dz}\log\frac{1-p^{-z}}{1+p^{-z}}\big|_{z=1} = \frac{2 p\log p}{p^2 - 1}$), so $\frac{D_{a_S}''(z)}{D_{a_S}(z)} = \frac{2}{(z-1)^2} - \frac{2\beta_S}{z-1} + O(1)$ with $\beta_S := \gamma_E + \sum_{p \in S}\frac{2 p\log p}{p^2 - 1}$ produces a **double pole** at $z = 1$. Expanding $\operatorname*{Res}_{z=1}\!\left[\frac{D_{a_S}''(z)}{D_{a_S}(z)}\frac{d^z}{z}\right]$ via $\frac{d^z}{z} = d\bigl(1 + (\log d - 1)(z - 1) + O((z - 1)^2)\bigr)$ requires each control's own exact two-parameter Perron drift compensation
  $$M_{2,a_S}(d) := 2 d\log d - \left(2 + 2\gamma_E + 4\sum_{p \in S}\frac{p\log p}{p^2 - 1}\right)d = 2 d\log d - (2 + 2\beta_S)d, \qquad R_{a_S}(d) := W_{2,a_S}(d) - M_{2,a_S}(d),$$
  with matched known component $A_{a_S,Y}$ convolving the exact discrete first difference $\Delta M_{2,a_S}(m) := M_{2,a_S}(m) - M_{2,a_S}(m - 1) = 2\bigl(m\log m - (m - 1)\log(m - 1)\bigr) - (2 + 2\beta_S)$ ($M_{2,a_S}(0) := 0$, $0\log 0 := 0$) directly against $a_S(q)$ via $\frac{1}{(\log X)^2}\sum_{m q = n \le T(Y)} \Delta M_{2,a_S}(m)\,a_S(q)\,\varphi_n(X)$, together with the small-divisor slice $d \le D_{0,\mathrm{eff}}$, floor jumps, and endpoint (matching [`evaluate_control_matched_point_arb`](file:///c:/Development/Projects/reimann_scope/tc/mixed_arithmetic_covariance.py#L2219-L2255) in [mixed_arithmetic_covariance.py](file:///c:/Development/Projects/reimann_scope/tc/mixed_arithmetic_covariance.py); note $A_{a_S,Y}$ does **not** satisfy Liouville's contraction theorem because $\mathbf{1}*a_S$ has positive natural density $\prod_{p \in S}\frac{p}{p+1} > 0$, making $\|A_{a_S,Y}\|_Y^2 \asymp Y$!).
